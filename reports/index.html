What these plots represent

A = 2N2222/2N2907; B = BC337/BC327; C = BD139/BD140. These are the first three amplifier circuits from the research discussion, with a DC input return, base stopper resistors, and output decoupling/stabilization added consistently. They are separate circuits fed by the same simulated signal source.

This is an educational circuit comparison, not a reliable transistor-quality ranking. The missing LM741 model is replaced by the same generic one-pole model in all three branches. It has no slew limiting, output-current limit, input bias, offset, or noise. The BC and BD transistor models supplied in the discussion are simplified and unvalidated. None of these plots is a measurement of your parts.

What to look for

At low level, all three outputs should almost overlap because global feedback sets gain near 11. Increase amplitude to reveal modeled compression and clipping. A rounded or flat peak shows loss of proportional gain. Transfer curves show this as a bend away from a straight diagonal. Difference plots magnify departures from the gain-11 target.

At high input, the square-like waveforms and wide transfer loops expose saturation-recovery limitations of the generic op-amp model. Treat those figures as a reason to improve the model and investigate the circuit, not as expected bench traces.

The discussion predicted BD139/BD140 would always be cleaner and swing farther. These models do not establish that claim. BD devices can be useful for current handling and heatsinking, but lower current gain can demand more base drive. Available bias current and the op-amp drive capability matter. There is no predetermined winner here.

In real builds, thermal behavior, bias tracking, device spread, layout and feedback stability can change the result. A 741 can introduce high-frequency slew distortion that this model cannot show. Compare multiple actual samples before treating transistor type as the cause of a difference.

3. High signal: common resistor values

The requested 3.3 V peak output drives the approximation into saturation. These runs show abrupt switching and hysteresis, not just normal sine-wave peak clipping. The generic op-amp can accumulate internal pole error during saturation and recover unrealistically; these severe shapes must not be treated as predicted hardware waveforms. Base-drive and transistor parameters also affect where saturation begins.

Repeat the experiment

python scripts/compare-transistor-pairs.py --gui
python scripts/compare-transistor-pairs.py --bias common --input 0.15 --gui
python scripts/compare-transistor-pairs.py --bias common --input 0.30 --gui

GUI mode leaves ngspice open; enter quit when finished. Without --gui, each run saves a deck, log and CSV under results/. The report builder requires NumPy and Matplotlib:

/disk1/tmp/amps-report-venv/bin/python scripts/build-comparison-report.py
