Parts lists by amplifier project

Use the LM386 KiCad list for the generated graphical project. Other lists are draft extractions of the current simulation circuits. Their model limitations and known circuit issues still apply. Simulation sources and external test loads are separated from circuit parts.

Do not add all CSV quantities together: many files are alternative versions of the same project. Op-amp channel quantities differ from package quantities. Wiring, sockets, breadboards, connectors absent from the netlists, decoupling/layout improvements and heatsinks must be considered separately.

For the first three-way fixture: three independent 8-ohm dummy loads, shared generator, four scope probes, a suitable split supply, wiring and temperature/current measurements. Use measured resistor dissipation and device ratings to select power ratings. IC sockets are optional. The transistor-pairs-comparison list includes all three channels, so do not also add P01/P02/P03.

Projects without a final parts list

  • P10 TDA2822: exact device/package and circuit still need selection. LM386 alternatives are listed below.
  • P11 TDA2030: circuit, supply, heatsink and load ratings still need selection.
  • P12 battery switching: conceptual netlist only; not a complete hardware purchasing list.
  • P13 final PCB: depends on the amplifier selected after evaluation. The current LM386 PCB is an unrouted learning board.
